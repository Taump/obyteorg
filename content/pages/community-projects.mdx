    ## Made On Obyte - Project Directory

    As it might not always be obvious what technology is under the hood of a specific project or use case, a project was launched aiming to gather an overview of all the various projects built on the Obyte platform. It is called <a href="https://madeonobyte.org" target="_blank">Made On Obyte</a> — plain and simple. Here, you will find a repository of community projects that in one way or another utilizes one or more features of Obyte.

    Made On Obyte recently introduced a <a href="https://madeonobyte.org/crowdfunding" target="_blank">crowdfunding feature</a>, allowing community projects to launch campaigns to raise funding for their project or startup. So with Obyte, every community project has a full set of tools covering the entire journey from initial inception of an idea all the way to a final product. So regardless of whether you prefer a traditional crowdfunding campaign or want to run an ICO to fund your project, all the features are already on Obyte, ready to be used.
  </FlexBlock>

  ## Tap into the Obyte community

  On the Obyte Discord an entire group of channels is dedicated to community projects. Here, projects can have their own channel to make announcements, exchange ideas with developers of other projects or to refer customers or clients to, in case they need support.

  Projects may also apply for [grants](/grants) from the Obyte Foundation.

  <DevCallout image="/media/theme/community/svg1.svg" title="Existing projects">
    Over the years, many projects have been built by the community. Here are a few, for a more thorough list see <a href="https://madeonobyte.org" target="_blank">Made On Obyte</a> website.

    - <a href="https://obytejs.com" target="_blank">obyte.js</a>: a pure and powerful JavaScript Obyte library, it is used by almost every dApp on Obyte
    - <a href="https://obyte.io" target="_blank">obyte.io</a>: a data explorer for Obyte
    - <a href="https://pollopollo.org" target="_blank">PolloPollo</a>: a charity platform that enables direct, safe, and transparent donations based on Obyte [smart contracts](/platform/smart-contracts)
    - <a href="https://asset.obyte.app" target="_blank">Asset registry</a>: allows you to issue assets and register human readable names for them
    - <a href="https://blackbytes.io" target="_blank">Blackbytes.io</a>: a [Blackbytes](/platform/blackbytes) exchange
    - <a href="https://github.com/Papabyte/Byteduino" target="_blank">Byteduino</a>: a lightweight C/C++ implementation of Obyte node for Arduino ESP8266 and ESP32
    - <a href="https://orider.obyte.app" target="_blank">Orider</a>: a ride sharing app built on Obyte [smart contracts](/platform/smart-contracts)
    - <a href="https://cryptothings.gallery" target="_blank">Cryptothings</a>: a NFT marketplace and licensing solution

    See more projects on <a href="https://madeonobyte.org" target="_blank">Made On Obyte</a>.
  </DevCallout>
